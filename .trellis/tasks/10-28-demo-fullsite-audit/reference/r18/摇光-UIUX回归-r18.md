## 〇、置顶
- **P0 · 运行诊断的交互逻辑（根因，含准备相遇失败）**
  - 准备相遇「初始衣柜」失败时，失败原因只写「原因已记录」，看不到输入、输出和具体原因。
  - 「查看技术详情」会跳到单独的任务页。页面里「执行阶段」既是 Tab 名，各行又都叫这个名字；所有时间都在同一分钟。页面最后显示「没有可执行的恢复操作」，和入口卡片上的「恢复此环节」矛盾。
  - demo 的做法是：
    - 失败时写一句人能读懂的原因，并说明「已有角色与世界会保留」。
    - 三个按钮是「恢复原任务（主按钮）/ 查看任务记录 / 先开始相处」。
    - 「查看任务记录」进入诊断与任务，带上下文横幅，还有「返回初始化流程」按钮。
    - 任务 Dialog 顶部是红色原因，下面是分阶段进度，底部有「从失败处重试 / 从头执行 / 重置 / 取消」。
    - 模型调用详情里有模型、用途、耗时、请求摘要、返回内容。
  - 项目和 demo 的差异：
    - 外层 Tab 里还套了一层内层 Tab。
    - 调用表格有 20 行，横向被截断，有「尚未关联角色」，摘要里是英文原文。
    - 调用 Sheet 是三段折叠区，没有返回摘要，也没有重试。
    - 通知进入的是整页，侧栏高亮却在管理中心。
    - 服务诊断里有「Core readiness」和黑框。
    - 18 条「独立目标规划」几乎一样，没法区分。
  - 证据：demo `07b0a9b5…`、`b3e662be…`、`0db56a51…`、`f0b5a7e9…`、`296a770d…`、`22e0fbb2…`；项目 `da432494…`、`73e26d4e…`、`e971ba7d…`。
  - 后端原因：`generic_llm` 没有绑定模型，日志里的错误码是 `initialization_role_unconfigured`，并且标明可重试。前端没有把这个原因和「去配置模型」的入口展示出来。

## 一、r17 问题复查结论
大部分仍存在，下面只列有变化的：
- **已修复或有改善**
  - 角色库、世界卡、衣柜和物品换成了插画封面，但角色头像仍是首字，三张角色封面相同。
  - 世界页的世界数量正确，卡片显示地点和人物数，但仍缺类型。
  - 媒体的「在素材库中隐藏」改成了 Switch。
  - 动态列表多了「所有人的动态」，但默认选中的是苏晚；卡片上有了心形。
  - 通知有了图标和「已读」标记，但没有彩色类型图标。
  - 人物的「关于你」「你们的关系」可以显示了，但内容都是空的。
  - 创作沙盒不再露出 `character_template` 和 `schema`。
  - 对话右侧预览不那么拥挤了。
- **仍存在（全局）**
  - 技术字段外露：动态、通知、媒体的 JSON，以及 sha256 等字段。
  - Accordion 大量存在：日程、日记、档案、世界设定、设置、各类详情。
  - 详情用的是居中 Dialog（demo 也是 Dialog，等你定以哪个为准）。
  - 「读取最新版本并保留输入」按钮仍有 6 处。
  - 选中的 Tab 和关闭按钮带黑粗框：媒体、世界事件、服务诊断。
  - 很多按钮看起来像纯文字。
  - 内容区偏宽、贴左。
  - 悬浮保存条会遮住内容。
- **仍存在（模块）**
  - 对话：状态文案过长；「查看状态」点了没反应。
  - 此刻：仍是纯文字空状态，三个入口重复。
  - 日程：Accordion 和自绘日期框。
  - 目标：文字链接。
  - 衣柜：多余的刷新图标。
  - 日记：有折叠区，留言区是灰色，「未形成正文」重复出现，「只看收藏」不像 Switch。
  - 记忆：多一个 `>` 按钮。
  - 档案：「尚未提供」出现 9 次，性格维度没有进度条。
  - 世界：
    - 物品显示 `dress / full_body` 这类代码。
    - 地点编辑露出 JSON 数组。
    - 世界编辑缺「场景印象」。
    - 世界事件缺 Switch 和详情按钮。
  - 媒体：
    - 详情图片外有黑描边，「编辑库信息」是弹窗上再叠弹窗。
    - 列表缺「喜欢」和类别名。
    - 「Visual Identity」是英文。
    - 生成画面的必填项没有标记。
    - 显示头像缺「用名字代表自己」，也没有用 RadioGroup。
  - 动态：评论按钮重复，输入框没有占满宽度。
  - 通知：「需要你决定」是空的大卡片；直接显示 `schedule.current_day`。
  - 角色库：缺标签筛选，简介是占位语。
  - 向导：
    - JSON 模式布局错乱。
    - 「尚未配置模型」的提示被操作栏压住，也缺「填入示例」。
    - 时区默认 `America/Los_Angeles`（demo 是 `Asia/Shanghai`）。
    - 步骤条是自制的。
  - 创作：标题重叠，资源重名，必填无星号，JSON 在折叠区。
  - 命令面板：缺搜索图标，聚焦是粗青色边框。
