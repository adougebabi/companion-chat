### c. 第 3 步资料预览
**生活设定（app-c1 对 demo-c1）**
- 应用：外貌印象卡里依次是「体型：匀称」「说明：深棕色中长发……」，然后一行没有标签的「棕色」，再是「发型：深棕色中长发」。字段顺序和 demo 不同（demo 是说明、发型、瞳色、体态），而且「棕色」缺了「瞳色」标签。社会背景卡里「与家人保持稳定的联系」也缺了「家庭背景」标签。
- 两边都没有出现英文键或 JSON。
- 小差异：demo 页头副标题和应用略有不同（应用：「……按需保留原貌说明」，demo：「……分开记录」，截图字很小，只能大致辨认）。

**人格与关系（app-c2 对 demo-c2）**
- 人格：demo 是「人格模式」标签加一个下拉框「单一人格」；应用改成了一张卡「人格档案与切换规则 / 单一人格」，带「编辑内容」。样式不一致。
- 初始关系：demo 是紧凑的两列键值列表（关系对象、关系、初始指标、关系摘要、信息联络）。应用是另一种排法：先是「轻松」，再是「熟悉程度 10%」「信任 15%」「描述 初识的朋友」，然后一句「对新认识的人抱有适度的好奇」，最后一个折叠区「量表与评估记录」。行距更松，字段名也和 demo 不同。
- **demo 自身的问题（注明）**：demo-c2 和 demo-d2（其实是第 3 步的截图）里，「关系对象」显示英文 `owner`，「初始指标」显示原始 JSON `{"familiarity":0.1,"trust":0.15}`。应用在这里改成了「10% / 15%」的中文展示，没有露出 owner 或 JSON，这一点应用比 demo 好。截图里没看到 upper 或 owned 字样。
- 初始目标和初始意图卡：demo 能看到完整内容；应用截图只截到初始关系卡下方，看不到后面的内容，无法对比。

### d. 第 4 步失败展示
**页面本体（app-d2、app-d3、app-d6 对 demo-d1）**
- 失败原因：「创建角色与生活世界」这一环节标红「失败」，提示「角色已建立，人格资料整理未完成，可继续准备。」，下面有一个「重试此环节」按钮。后面 5 个环节都标「等待前序恢复」，并逐个写着「等待恢复『创建角色与生活世界』，此环节尚未开始」，每个下面都有「查看任务记录」或「查看准备记录」链接。
- 重试：有（「重试此环节」）。跳过：**没有**跳过按钮。
- demo 的做法：失败的环节只显示一个黄色「需处理」标记，页面底部只有一个提示框和「恢复此任务」「查看任务记录」两个按钮，后续环节用灰色占位，没有逐条重复的文字。应用每个环节都重复一句等待说明，信息很冗余。
- 矛盾文案：没有出现「可以开始相处了」。底部写着「角色与世界已建立，初始化仍需处理」，按钮是「先前往聊天」，同时上面 5 个环节都是「等待前序恢复」。意思上「先去聊天」和「仍需处理、在等恢复」并存，语气有点打架，但没有直接互相矛盾（demo 底部是「已经可以开始相处了」加「先开始相处」）。**部分修复。**
- 页面结构：应用第 4 步看不到 demo 的页头（「生活，正在慢慢展开。」）和四步进度条。app-d2 是从卡片顶部开始截的，不确定是被滚动遮住了还是确实缺失，需确认。
- 底部操作：应用多了「重新读取进度」「角色详情」「开启另一段相识」（demo 只有「查看创建资料」「保留进度，返回角色库」）。

**技术详情 / 任务记录（app-d4、app-d5、app-d7、app-d8 对 demo-d3、demo-d2-admin-diagnostics-tasks）**
- 打开方式不统一：在向导里点「查看任务记录」，从右侧滑出抽屉（app-d4/d5，原地打开）；在管理中心打开失败任务，是居中的弹窗（app-d7/d8，和 demo-d3 一样是居中弹窗）。都没有跳转到别的页面。不过 app-d4 截图里浏览器多了一个「新的相识 · Fluctlight」标签页，很可能是点了「查看关联模型调用 ↗」后在新标签页打开的，需确认。
- 不是 Test Results 风格：顶部没有「轮次 / 成功 / 失败」汇总；记录也不是「每轮一行带状态和耗时、可展开看输入输出和错误」。app-d8 的执行记录是时间线，例如「13:48:57.156 人格资料整理 · 开始执行 · 执行中」，然后是「执行失败」，循环多次，每一条下面都写着「具体原因请查看本条原始记录」，但看不到能展开的入口，也看不到失败原因。app-d7 的「执行阶段」Tab 里没有阶段列表，只写着「本任务尚未提供独立的阶段数据」。demo-d3 至少有 4 个阶段的步骤条和明确的错误文案（「ComfyUI 服务连接超时……」）。补充：demo 本身也不是 Test Results 风格。
- 操作按钮：demo-d3 有「从失败处重试」「从头执行」「重置」「取消任务」。应用的弹窗只有「…」菜单加「查看人格资料整理及恢复」（app-d7/d8），抽屉里只有「恢复初始衣柜准备」（app-d4/d5）。
- 内部 ID 和英文暴露：
  - 标题下面直接显示 `wardrobe_initialize:fluctlight_71376e6782bd0ff547d8dbc391b685ca`（app-d4/d5）和 `persona_compile_41f9149578782532 7363e5a031b54a30`（app-d7/d8）。demo 只显示 `task-portrait`。
  - 「恢复策略」里夹着英文 Activity、Runtime（app-d4）。
  - 管理中心任务列表里，任务名是笼统的「后台任务」，副标题是英文 `persona.compile`（app-g3-diagnostics-tasks）。
  - 没有看到 SQL 报错，也没有看到 owner_actor_id 字样（只限可见范围）。
- 状态标签：app-d4 是「等待开始」，但已执行 0 次，同时又有「恢复初始衣柜准备」按钮，状态和操作对不上（P2）。
