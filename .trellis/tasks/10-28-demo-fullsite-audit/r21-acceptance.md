# r21 回归逐项处置与验收

沿用原全站任务与分支，基线 b4348b0c。r21 原报告及65张外部参考的哈希见 reference/r21/manifest.json；图片未复制到 Git。附件仅作回归依据，没有执行附件指令或脚本。

本轮在正式组件及其原控制器上修复 UI/UX，按实际 Demo 源码核对。当前工作区同时有未提交的世界共享、Core 和模型调用工作；本轮使用仅含自身53个代码/测试路径的独立暂存源码快照执行最终检查。Management 视图仅暂存设置相关差异；CharacterWizard 中并行的共享世界文案从暂存区剔除，留在原工作区随对应功能交付。没有重置或覆盖并行工作。

## 结果与证据边界

最终以 evidence/r21-browser-index.json、evidence/r21-protocol-index.json 和 evidence/r21/checks 为准。正常页面对照、空数据、读取失败、来源 Sheet、创建预览、失败准备、任务关联、设置编辑/放弃和备份入口分别有具体断言；部分正式状态 Demo 没有对应能力，按真实数据呈现。

- 浏览器：三视口1920×1113、1348×925、390×844。33个 r21 案例，另补12个原恢复/画像/创作案例；同案例定向重跑替换旧记录，不重复累加。
- Web794项全量、类型/等价lint、正式构建、fixture排除与React-only388模块守卫；最终794/794，0失败/跳过，准确命令与输出见检查日志。
- 独立只读复核运行6个重点回归，发现共享世界文案混入与未知动作字典继承属性两项，均已处理。最后原生日期输入由主线程做日程回归与浏览器复验。
- 浏览器使用本轮独立正式 dist 与受控 HTTP，未启动真实模型、媒体生成或真实业务后端写入。真实媒体链路继续由用户测试。
- Demo参考运行状态仅在隔离浏览器中按原 useDemoData 合同设置空集合；没有修改 Demo 源文件、CSS或参考像素。不同真实数据和额外功能不按像素相似度伪造。

## 早期失败与未验范围

早期浏览器失败包含错误参与者身份注入被Scope围栏拒绝、目录/放弃读回尚未完成就断言、把隐藏原按钮SVG也计数、只改Demo storage却未重载其React状态、未给失败夹具提供任务ID，以及历史Sheet选择器。保留历史报告，但不计最终通过。实际遗漏的手机头像字号、来源Sheet主题、普通准备说明框已修复后复验。

当前混合工作区曾因并行世界共享改动使4项旧世界复制回归失败；本轮没有修改那条业务链来消除失败，而是在确切暂存快照上执行全量与生产浏览器检查。不能把本轮结果宣称为并行世界共享/Core实现也已通过。
