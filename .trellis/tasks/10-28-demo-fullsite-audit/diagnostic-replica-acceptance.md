## 明确保留的正式能力差异与未验边界

1. Demo 的四阶段图像任务和模拟恢复按钮不能复制成衣柜任务事实；正式仅呈现已有两阶段及 allowed_actions / 领域恢复。无跳过 API 就没有假按钮。
2. 模型详情为真实记录、日期、错误和完整请求响应；不存在的响应或调用序号不能补造。额外技术入口及真实筛选是正式能力，放在次级层级。
3. 服务诊断使用真实读取、当前浏览器探测和明确发起的测试回执。配置已保存不表示模型可用；ComfyUI 连接成功不表示图片生成完成。Demo 的“前端模拟”等文字替换为真实语义。
4. 任务页没有编辑业务草稿，因此该页面草稿编辑不适用；创建页草稿异常分类的既有成果保留，本批只定向复验原地任务/关联调用/恢复返回。未增加后端架构、测试按钮或任务控制能力。
5. 本批覆盖的读取/提交失败、处理中、受理未完成、任务失败恢复和来源返回有各自证据；不能扩大成每个任务类型、完成后完整 reload、全部导出/清理、全部通知路径和八场景均已验收。
6. 旧的 diag-approved 中宽屏任务筛选曾因 click 超时失败，不能写成 30/30；后续 diag-visual-final 和定向最终复验才是本文索引来源。早期失败和中间版本继续保留为历史。

本轮只给原 177 行矩阵追加精确观察，保留三维状态和八场景状态。全站任务仍为 in_progress，真实媒体生成继续由用户测试。所有图片均不提交。
