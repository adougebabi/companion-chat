# 媒体生成提示词与进度日志

## Goal

让本地图片/视频生成在开发检查器中提供可确认的最终提示词与真实执行进度，尤其是以本地命令运行的 h3 视频生成；用户无需从超长媒体意图 JSON 反推实际生成内容或盲等命令结束。

## Confirmed Facts

- 当前开发检查器的媒体作业条目将超长 `inputIntent`、`promptSummary` 与状态直接并排显示；截图所示布局不适合快速确认最终画面或执行状态。
- `submitMediaJob()` 已在提交前生成最终 provider prompt；该结果可作为“最终实际提示词”的唯一展示来源。
- h3 使用同步的本地 `spawn(..., {shell: false})` 进程；当前忽略 stdout，仅保留少量 stderr，且未写入 job/debug API。
- 现有 `companion_jobs` 已有 `result_json`、租约、重试和人格范围，debug-context 已是本地开关保护、脱敏且每人格最多 10 条媒体作业的诊断接口。
- h3 进度不一定输出百分比；第一版必须在没有明确百分比时显示阶段、耗时和最新输出，而不是按耗时推测百分比。
- 工作区已有未提交的 Telegram/时间线相关前端和任务文档变更；本任务不覆盖或重置这些改动。

## Requirements

### R1. Final prompt observability

在媒体调试条目中优先、清晰地展示最终送入当前 provider 的提示词。提示词应使用当前 debug 脱敏和长度限制；原始媒体意图降为可选的次级诊断信息，不应再占据主视觉位置。ComfyUI 与 h3 都使用中性的“最终 provider 提示词”标签。

### R2. h3 execution progress

采集 h3 的 stdout 与 stderr，解析受控阶段和仅由显式输出得出的百分比。每个 h3 attempt 持久化一个有界进度快照：阶段、尝试次数、开始/更新时间、已耗时、显式百分比（可为空）、最新脱敏输出、输出来源和输出计数。

### R3. Durable and lease-safe logging

进度存入当前 job 的 `result_json.progress`，不新建首版日志表，也不把输出累积进重试输入 `payload_json`。所有进度更新必须受当前未过期 lease owner 保护；重试会重置 attempt 进度，成功/失败最终结算必须保留最终快照。

### R4. UI and privacy

开发检查器显示 provider、最终提示词、阶段、百分比或“未报告百分比”、运行耗时及最新本地输出。日志只在现有本地 debug inspector 中出现；不得向普通聊天、bootstrap、媒体 URL 或公开设置暴露命令参数、绝对路径、模型目录、完整 stdout/stderr 或未脱敏敏感信息。

### R5. Fallback and tests

无百分比、无任何进程输出、ANSI/回车刷新、超长输出、命令失败、lease 失效和重试均有稳定显示/持久化行为。保留现有 ComfyUI 调试和作业兼容行为。

### R6. One logical media task per user request

ComfyUI 的内部 poll job 是原媒体任务的实现细节，不能在媒体调试区域作为第二张独立任务卡出现。调试 API 必须把 poll 的等待、失败或完成状态聚合回其 message/activity 对应的源图片/视频任务，保留源任务的最终提示词和原始意图。

### R7. Simplified chat media mode

提供持久化的“简化媒体模式”设置。开启后聊天窗口不得创建图片或视频元素、不得发起媒体资源加载；它只显示紧凑的隐藏/生成状态，同时仍允许媒体任务创建、后台运行、消息状态更新和开发检查器中的触发/调试。

## Acceptance Criteria

- [x] 调试检查器先显示最终 provider 提示词，截图中的超长输入意图不再作为主要确认信息。
- [x] h3 执行时，检查器能显示真实阶段、已运行耗时、最近一条脱敏输出与当前尝试次数；有显式百分比时显示百分比，没有时明确显示未报告百分比。
- [x] 刷新页面或重新读取 debug-context 后，正在执行/已完成/失败作业仍保留最后一个安全的进度快照。
- [x] 旧 lease 的进度回调不能覆盖重试后新 lease 的进度；成功/失败结算不会抹掉已有 progress。
- [x] 不记录完整命令、绝对路径、完整输出历史或未脱敏凭据；最新输出有紧凑长度上限。
- [x] 自动化测试覆盖 percent/null、输出清理和节流、lease guard、终态保留及 debug DTO 脱敏。内置浏览器与本地监听端口处于隔离网络，无法完成实时截图验证；已执行源码级窄屏断点检查与本地子进程流测试。
- [x] 一个用户可见媒体请求在检查器中只显示一张任务卡；内部 ComfyUI poll 状态、错误和完成态均回投到源任务。
- [x] 开启简化媒体模式后，聊天消息不渲染或加载 `<img>` / `<video>`，但媒体任务仍能在开发检查器中触发并观察。

## Out Of Scope

- 不承诺为 h3 构造基于耗时的虚假百分比或模型内部推理指标。
- 不在首版创建可检索的逐行日志表、实时 SSE 控制台、远程日志服务或普通用户可见的进度条。
- 不改变媒体意图、提示词编译、provider 配置或现有消息原位替换模型。

## Resolved Decision

以现有本地开发检查器为唯一的直观入口；不新增终端进度日志。检查器中的媒体区域将升级为可自动刷新的可视化媒体任务面板，让最终 provider 提示词、真实阶段、耗时与最新输出可以直接查看。
