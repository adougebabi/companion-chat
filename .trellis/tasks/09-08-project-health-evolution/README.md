# 本次做什么，不做什么

本轮只完成详细规划，任务保持planning；尚未开始业务实现。

## 下一次实施：A批

1. 修当前人格/输入字段/消息重复，保持单次认知回复。
2. 接通错误关联、内部阶段原因、attempt与诊断失败旁路。
3. 在页面直接呈现失败阶段、具体原因、影响和下一步；工作流证据按需展开，无需导出或手填ID。
4. 补PG持久deadline，解决唤醒依赖Redis通知的恢复缺口。
5. 修记忆/反思合同错误，建立排除聊天历史干扰的记忆验证。
6. 补最终请求与记忆各阶段计量，为下一批提供依据。
7. 补目标与意图最小推进：实体可更新、进度可写回、行动有归属、成功/失败可反馈，页面可看推进与阻塞。

## 本批不做

完整prompt预算框架、全库记忆检索重构、自动纠错/记忆合并、后台全部单次化和工作流全面减重留到B批基础迭代。
完整意图到期/事件触发和自动重规划归B05，不把目标进度显示当成这些能力已完成。
头像、群聊、后代、图生图和全面美化留到C。
本批不做诊断导出/下载/打包，现有导出接口不顺手删除。
不重写系统、不加每轮第二次模型回复、不删除历史/真实记忆、不放开权限、不部署。
