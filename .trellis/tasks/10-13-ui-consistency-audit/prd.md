# Fluctlight 全站 UI 与交互统一化重构

## 目标

将已经完成的巡检结论落实为第一、第二期全站改造，使聊天、动态、设置、诊断、人格详情与治理形成一致、可理解、可恢复的成熟产品体验。

## 已确认背景

- 目标为用户指定的局域网 Fluctlight 实例；入口已有登录态。
- 用户已同意任务建档，并在收到巡检报告后明确要求第一、第二期全部处理。本任务范围扩展为产品代码重构；实施前仍须完成最终规划审阅。
- 项目现有设计上下文位于 `.impeccable.md`，采用亮色、低噪声玻璃表面与蓝色操作强调；用户要求以精品网站设计品质评审，并统一使用 Lucide、禁止界面表情符号。

## 范围与要求

- R01：统一颜色/前景/圆角/间距/焦点/动效 token 与共享 Button；解决低对比度、黑色默认按钮割裂和小触控目标（F01–F03）。
- R02：统一 FormField、行内校验、错误提示、加载/空/失败状态、确认弹窗；错误隔离于所属动作，保留草稿与恢复入口（F04–F06、F16–F17）。
- R03：统一名称解析、中文状态、时间展示与Lucide图标；保留完整ID与原始数据的高级可达性（F08–F10、F15）。
- R04：统一诊断过滤、摘要、分页、原始数据查看和Workflow行；显示Run/状态/时间，避免相同ID行不可区分（F12–F14）。
- R05：第二期收敛治理背景编辑入口，明确对象、来源及纠正/变更语义，保留CAS与证据治理契约（F07）。
- R06：将常用运行策略表单化；唤醒展示实际固定10分钟周期与启用开关，诊断保留展示实际生效规则；媒体提供已保存工作流、用户导入、校验与高级JSON编辑；人格详情按常用资料/生活/技术属性分层（F09、F11）。
- R07：完成全站排版、表面层级、响应式、导航和微交互动效统一，支持reduced-motion与键盘操作。

巡检依据：`artifacts/ui-audit-2026-10-13/report.md`与`coverage.md`，含16项现场问题与1项源码线索及全部file:line锚点。

## 验收标准

- AC01：共享按钮普通文字对比度至少4.5:1；移动操作最小40px，主导航至少44px；纯UI图标全部Lucide，无表情符号。
- AC02：必填、全空白、格式和服务失败均有中文反馈；关闭弹窗与切换栏目不带入无关错误，失败保留草稿；加载不冒充空态或已保存配置。
- AC03：治理背景具有清晰单一主入口，所有编辑对象、版本与修订语义可见；既有CAS、幂等和事实版本校验保持成立。
- AC04：常用配置可通过标准表单编辑；高级JSON保留可达路径，media/自治等开放对象不因保存丢失未展示字段或工作流分支，queue/wakeup封闭schema按服务器allowlist保存；不把尚无消费实现的存储配置表现为已生效能力。
- AC05：诊断默认摘要，统一过滤重置和日期输入；各Workflow运行可辨识；分页、相关性与原始非图片诊断内容不丢失。
- AC06：所有一级/二级入口与详情/治理完成桌面、390px及320px回归；弹窗仅正文滚动；200%缩放可达，无横向页面溢出，聊天草稿/IME/滚动锚点不丢失。
- AC07：typecheck、现有web测试与production build通过；对状态/校验/保存往返新增必要行为测试；真实构建浏览器验证有前后截图和实际覆盖记录。
- AC08：用户局域网业务数据不被验证过程修改；提交/删除/生成通过隔离fixture核验，真实服务验证边界如实报告。

## 不在范围内

后端模型/自治/目标语义变更、身份与记忆数据迁移、服务连接故障修复、生产部署、线上破坏性测试。不将客户端呈现优化误当成真实Provider可用性修复。

## 关键决策与风险

- 采用现有亮色、安静、可信的产品气质；精品完成度体现为排版、组件精度和反馈完整性。
- 两期在一个任务内顺序推进共享基础、反馈、资料、设置、诊断与全站验收；各批有独立回归点，最终统一验收。
- 背景资料统一呈现入口，Owner和其他Actor保持各自的并发版本适配器；可信Owner身份来自已有认证session.actorId。
- 当前没有服务端媒体模板目录API，导入只承诺结构校验与已保存工作流预览；真实执行结果以服务响应为准。
- 全局CSS、异步草稿与设置开放对象序列化为高影响变更，必须有行为测试和production-build浏览器回归。局域网服务连接失败按真实状态反馈，不以fixture通过替代真实服务通过。

规划已收敛，无待决定的产品问题；进入实施前需用户审阅本次完整方案。

## 实施中的必要边界同步

独立核验发现浏览器Owner背景allowlist仍为八字段，与已有Core/OpenAPI十字段契约冲突。仅在browser routes同步interests/preferences并补真实路由测试；保持当前事实CAS、授权及领域语义，不属于后端行为改造/迁移。验收结果及平台限制见artifacts/ui-refactor-2026-10-13。
