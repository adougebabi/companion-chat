# Design

Keep existing React pages, shadcn Radix primitives and domain controllers. Change reading projections without rewriting imports or saved business data. Preview dictionaries cover known schema/extensions; unknown labels remain distinguishable. Task rows group actual recorded attempt/round metadata; lifecycle-only records are clearly identified without inventing model rounds. Sheet reuses existing TaskRecordDialog Sheet branch and recovery portals. Skip defers optional preparation with saved recovery and never forges completion. Defaults live in Core decision config and never migrate saved settings. Local browser backups use actual export/import scope and distinguish browser copies from server maintenance backups. World projection hides known technical metadata while preserving data in source.

Expected owners: creation preview/wizard; task presentation/detail/overlay; People presentation/AboutYou; Library/Goals/People empty states; World record; decision defaults; data tools; owning tests/CSS. No prompt/model request changes, P2 cleanup, images in Git or accept tree writes.
