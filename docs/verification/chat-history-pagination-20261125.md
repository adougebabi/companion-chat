## 问题与修复

主聊天首次只读取最近 50 条消息，已有 loadOlder 动作没有页面入口。发送完成后把历史游标覆盖为最新一页的游标，会回退已读历史的分页位置。旧历史请求只按 conversation ID 隔离，不能排除离开后重新进入同一会话的迟到结果。

- 主聊天消息顶部接入“加载更早消息”，支持加载状态、失败后按原游标重试，读到最早一页后隐藏入口。
- 历史读取使用独立错误状态，不覆盖回复失败或禁用正常发送。
- 最新消息读回保留已加载消息及最早游标；历史请求同时核对角色、会话和请求代次，旧请求不能写入或清除新请求的加载状态。
- 会话历史窗口说明消息分批读取，并保留既有翻页、搜索和草稿语义。
- 未改后端保存规则、数据库、模型请求或提示词。
