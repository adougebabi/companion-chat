# M2-18 私聊工具动作的过期接管防重

受检基线 `576d2e318579cb18c6236b82a4db3c007cac47a6` 加本项四个生产文件
与测试文件；本项未修改模型配置、提示词、`fact_only` 开关或数据库结构。

隔离 PostgreSQL 中，受控 Provider 通过正式 direct 主链受理图片任务；测试
杀死自己的子进程，模拟领取及逻辑租约过期，同时保留回复时限。修复前同一轮
流式及 Worker 接管均产生两个真实 `media_intents` 和两条工具回执；排队状态
同样复现。领取权转移后，旧 `fact_only` 和旧 direct 执行也分别复现新建图片
任务并错误关闭新领取。真实红测和测试夹具失败均保留在
`m2-18-failure-history.log`；其中情绪动作场景的第二次写入被状态版本保护
拒绝，不能称为重复业务写入。

修复后，领取时检查已提交回执、活跃逻辑租约和同源草稿；不安全的未完成轮次
沿用 `agent_partial_committed` 状态，不自动再次执行模型或工具，原图片任务
保持原 ID 和 `pending`。工具事务及失败记录核对当前领取权，避免旧执行者
写入或覆盖新执行者。草稿本身和已绑定的图片保留恢复路径；同轮还存在独立
已提交动作时保留草稿并停止自动重跑。该保守策略不等于完整自动续写恢复。

`m2-18-final-regression.log` 为干净源码加本项改动的定向回归，退出 0、无
SKIP，覆盖流式及 Worker 的 `claimed`/`pending`、活跃租约、无动作恢复、
旧领取写入栅栏、纯草稿、绑定图片和独立图片共存，以及默认模型配置、
`fact_only` 切换、旧草稿、消息、超时和插件直接相关回归。另有含四处原有
草稿的 `m2-18-working-tree.log`，退出 0、无 SKIP。

本项使用受控 Provider，不调用真实模型或 ComfyUI；不证明真实模型语义、真实
图片交付或 T04/T06、M2 整体验收。旧进程崩溃后的部分提交现在明确停止，
后续如何在所有领域动作上自动续写仍须按原要求单独验证。
