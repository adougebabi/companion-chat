在隔离 PostgreSQL 的正式 Moment 准备路径中，不显式选择关系证据时，起始
提交 `d37da697d247bcb74c9b1b7d9de24d669790961c` 的 Writer 物理请求仍会删除

本项对默认关系视图选择已声明的业务字段和原有人物视图，保留业务对象嵌套值，
不改变关系条目范围。最终候选 2 项定向测试、12 项相关回归及含四处原有草稿
的工作区 2 项测试均退出 0、无 SKIP，见 `m2-16-final.log`、
`m2-16-regression.log`、`m2-16-working-tree.log` 和候选 manifest。

此结果仅覆盖默认关系视图，受控 Provider 不代表真实模型效果。默认关系和同一
已选关系证据可能同时进入上下文，尚需按 T03 的去重要求单独核验；其他证据
类型和 T03/M2 整体验收也未完成。
