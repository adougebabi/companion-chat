# 接入状态总表

状态只表示当前前端能否用真实接口完成该动作。构建通过不等于验收。本环境没有可用的 Core API，登录和写入没有做实机复验。

| 角色库 | `/library` | 部分接入 | 列表、创建、分组归入、状态、打开治理 | 移出分组入口、头像、卡片上的此刻一句话 |

全站回归时要一起看的约束：

- 未知角色链接停止显示其他角色的数据。
- 离开页面不取消服务端回合。
- 409 保留草稿。
- 创作预览不调用会话 `send`。
- 世界页不调用移动或改位置的接口。
- 回档页没有恢复提交。
