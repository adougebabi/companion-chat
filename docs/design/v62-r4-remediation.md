## 修复范围

- Provider 只接受裸对象或被一个完整 JSON/无语言围栏包住的整个正式内容。
  拒绝围栏外正文、思考内容、二次编码字符串、多对象及不完整围栏；
  不从正文提取可执行 ToolCall。可见回复中的代码块保持原文。
- persona_compilation 虽共用初始化模型用途，仍发送并校验自己的
  `persona_compilation_response` JSON schema；完整初始化保留其专用对象协议。
- 通用 final repair 保留上一次真实产物与工具回执，保持工具为空。
  完整初始化的失败不再触发隐藏的第二次生成，输入留待显式重试。
- 模型输出错误不再附加“修正原输入”的误导提示。
- 配置页保存按钮旁持续显示保存中、操作进度和确认后的结果；模型超时可留空，
  使用现有 120 秒默认值。无效显式值仍拒绝。配置控件使用稳定的中文可访问名称。
- 向导与衣柜页共用准备状态映射，识别 `can_recover` 覆盖原始 generating/queued；
  显示暂停摘要和后续等待前序恢复。保留原任务及单独恢复入口。
  后端成功前置条件未放宽，没有并行或跳过失败阶段。
- 资料展示消除平铺 traits 与规范 carrier 的精确别名；人格档案展示相对共同设定
  的差异。空白画像中的已声明 `key: value` 行显示中文并消除精确重复，
  普通叙述、未知扩展、不同值均保留。表达画像层级收敛；消息长短用中文选项，
  提交值仍为原枚举，未知既有枚举也保留。
- 通知默认按角色折叠、显示未读总数；不丢弃不同通知 ID。
  异常另按角色/类型分组并保留每次原诊断。修复后端 `#/…` 链接跳转与时间字段。
- 独立 Writer 从已验证 Core projection 补回角色/会话诊断关联；片段归纳、
  每日归纳、累计摘要不再全部记成同一 scenario，不修改其实际摘要语义或调度。
- 未配置 embedding 返回明确配置错误，保留已保存记忆；记忆页提供向量检索配置说明。
  没有生成空向量或把任务伪装成功。创作入口命名统一为“创作中心”。
